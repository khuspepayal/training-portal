# Training Portal

## Overview

A full-stack Training Portal built using Spring Boot, React, postgreSQL and Bootstrap.

The application supports role-based access for Admins and Students.

## Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* postgreSQL

### Frontend

* React
* React Router
* Axios
* Bootstrap

## Features

### Authentication

* User Registration
* Login
* Forgot Password

### Admin Module

* Add Course
* Add Schedule
* View Students
* Search Students

### Student Module

* View Available Courses
* View Course Schedule
* Enroll in Courses
* View My Enrollments
* View Profile
